# 换换 HuanHuan

一个面向中文用户的移动端单文件原型：C2C 闲置与技能互换，加上平台自营的精选商城。

## 运行

直接用浏览器打开 `index.html` 即可，不需要安装依赖或启动服务器。

- 单文件 HTML / CSS / JavaScript
- 无外部图片、字体或 CDN 依赖
- 按手机屏幕自适应，包含安全区处理
- 数据保存在浏览器 `localStorage`，不联网、不接入真实支付

## 页面

- 广场 / 推荐 / 发布 / 消息 / 我的
- 闲置与技能互换、发布、筛选、搜索
- 商品详情、购物车、结算演示
- 消息、个人资料、设置与隐私说明

## 说明

这是一个前端交互原型。页面中的价格、订单、物流、支付和客服流程均为本地演示数据，不产生真实交易。
